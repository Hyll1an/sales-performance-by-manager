# 📊 Sales Performance by Manager

Interactive Power BI dashboard developed to monitor sales performance through KPIs, time-series analysis, geographic visualization and manager-based filtering.

<img width="1272" height="712" alt="sales_performance_bManager" src="https://github.com/user-attachments/assets/299a14e6-03d7-406e-a45f-96d8974f4871" />


## 📌 Overview

This dashboard was developed to provide a comprehensive view of sales performance by manager.
It enables users to monitor key business metrics, analyze monthly revenue trends, compare store performance, and explore geographic sales distribution through an interactive and intuitive interface.


## ✨ Features

- 📊 Interactive KPIs for revenue, total orders, and average ticket.
- 👤 Manager-based filtering for individual performance analysis.
- 📅 Monthly revenue trend analysis.
- 🗺️ Geographic visualization of store locations.
- 🏪 Detailed store performance table.
- 📈 Interactive and user-friendly dashboard navigation.

## 🛠️ Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel

## 🚀 Getting Started

1. Download the `.pbix` file from the `dashboard` folder.
2. Open the file using Microsoft Power BI Desktop.
3. Explore the dashboard through the available filters and interactive visualizations.
